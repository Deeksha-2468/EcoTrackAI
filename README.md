🌍 EcoTrackAI

Carbon Footprint Awareness Platform

EcoTrackAI is a simple web application that helps users understand, track, and reduce their carbon footprint. It calculates an estimated carbon score based on daily travel, electricity consumption, and plastic usage, then provides personalized eco-friendly suggestions.

✨ Features

- 🌱 Carbon Footprint Calculator
- 🤖 AI-based eco-friendly suggestions
- 🏆 Achievement badges
- 📊 Sustainability progress tracker
- 🌿 Daily Eco Challenge
- 🔄 Reset functionality
- ✅ Input validation for empty and negative values
- 📱 Mobile-friendly interface

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🚀 How to Run

1. Download or clone the repository.
2. Keep these files in the same folder:
   - "index.html"
   - "style.css"
   - "script.js"
3. Open "index.html" in a web browser.
